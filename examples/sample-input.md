# Vendor Access Hub

A web application for managing third-party vendor onboarding, access requests, and approval workflows for internal teams.

## Users

- internal IT admins
- security reviewers
- external vendors

## Features

- vendor onboarding form
- approval workflow for access requests
- audit trail for approvals
- admin dashboard

## Constraints

- must be reviewable by security stakeholders
- small team shipping first version in 8 weeks
- prefer TypeScript and a single deployable unit initially

## Integrations

- email delivery
- SSO provider

## Notes

- customer security review expected
- sensitive internal business data
- Should vendors authenticate directly or through invitation links?
